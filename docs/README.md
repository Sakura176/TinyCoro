## 使用建议

1. **初学者**: 建议按顺序阅读 01 → 02 → 03 → 05 → 04
2. **面试准备**: 重点阅读 04 面试问题部分，结合 02 理解实现细节
3. **项目开发**: 参考 03 扩展方向，了解项目的发展潜力
4. **深入理解**: 阅读 02 各组件模块的详细说明，掌握技术细节

## 项目特点

- **技术新颖**: 结合 C++20 协程和 Linux io_uring 技术
- **高性能**: 在 I/O 密集型场景下表现出色
- **易用性**: 以同步方式编写异步代码
- **协程安全**: 提供专门的协程同步组件
- **完善测试**: 包含功能测试、性能测试、内存安全测试
