### 2.5 网络模块 (net/)

#### 2.5.1 核心类

1. **uring_proxy**: io_uring 的 C++ 封装
2. **io_awaiter**: 等待 I/O 操作完成的 awaiter
3. **tcp**: TCP 服务器和客户端的封装

#### 2.5.2 工作流程

```cpp
// 异步读取示例
task<void> async_read(int fd, void* buf, size_t count) {
    co_await io_awaiter{fd, buf, count, IORING_OP_READ};
    // 读取完成，继续执行
}
```

- **理解 io_uring 在网络编程中的优势**
- **掌握异步 I/O 与协程的结合方式**
